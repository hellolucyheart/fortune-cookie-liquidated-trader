A program that writes one fortune cookie line for a crypto trader who has just been liquidated (14 words) to `/output/entry.txt` for make.fun's "Fortune Cookie for the Liquidated Trader" bounty. The line is the whole entry, in the voice of a fortune slip: *"Your future is bright: the exchange has already collected it as a liquidation fee."* It scores six candidate lines against the judge's own criteria — the fortune-slip voice, the joke landing on the loss itself, originality, the liquidated trader's own condition, crispness — and writes the winner. It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
